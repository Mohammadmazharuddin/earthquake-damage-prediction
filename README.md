# Earthquake Damage Prediction

## Overview

Earthquake Damage Prediction is a machine learning classification project that aims to predict the level of damage caused to buildings during an earthquake based on various building and geographical characteristics.

The project covers data preprocessing, exploratory data analysis, feature engineering, machine learning model development, and model evaluation.

## Objective

The objective of this project is to develop a machine learning model that can classify the expected level of earthquake damage using relevant features from the dataset.

Project Workflow

1. **Data Understanding**
   Explore the dataset, identify the features, target variable, data types, and missing values.

2. **Data Preprocessing**
   Clean the data, handle missing values, and prepare the dataset for machine learning.

3. **Exploratory Data Analysis**
   Analyze the distribution of features and identify relationships between building characteristics and earthquake damage.

4. **Feature Engineering**
   Transform and prepare relevant features for model training.

5. **Model Building**
   Train classification machine learning models using the prepared dataset.
